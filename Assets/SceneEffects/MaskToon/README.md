# 面具三渲二材质

打开 **Tools → Rendering → 面具三渲二设置**，Unity 会选中当前面具材质，在 **Inspector / 检查器** 显示中文拉条。全局描边面板中的 **打开面具三渲二材质** 按钮也可进入。

当前默认是硬边亮暗二分，贴图和模型保持原样，材质使用两档受光来体现三渲二风格。

- **亮部亮度 / 暗部亮度**：分别调整两档的明暗，差距越大，二分效果越明显。
- **明暗分界位置**：调整受光面的覆盖范围，数值越大，暗部范围越大。
- **分界柔和度**：0 为严格硬边；增大后边界变柔和。
- **启用灰阶（三档）**：增加灰部，开放 **灰部亮度 / 灰亮分界位置**。灰亮分界应高于明暗分界。
- **整体曝光 / 贴图饱和度**：统一调整面具的明亮程度和颜色。
- **明显二分 / 亮灰暗三档**：一键应用预设，再继续用拉条微调。
- **高级：光向与色调**：可选择跟随场景主光方向，或用水平角、俯仰角自定义面具受光方向；也可调整三档色调、场景灯光染色及是否接收场景投影。
- 调整后点击 **保存面具材质**。

三渲二材质保留深度、法线和投影通道，与 **全局描边 → 傩戏面具** 分类兼容。新导入的面具名称即使是随机编号，使用该材质后也会自动进入面具描边分类。

原来的 Lit 材质备份保存在 `Assets/SceneEffects/MaskToon/OriginalMaterials/`。当前只替换面具材质的着色器，不改变摄影机、地形、灯光或物体位置。
