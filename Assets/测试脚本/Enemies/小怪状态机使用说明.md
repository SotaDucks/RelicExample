# 小怪状态机

脚本已接入现有 Kaoru 飞刀。场景、Prefab、动画片段和 Animator Controller 均需由你按下面的步骤配置，本次只修改脚本与说明。

## 行为

- 开始处于 Idle，玩家进入警戒范围后切换 Run 并追逐。
- 靠近到攻击距离后停止移动，播放一次 Attack。命中帧检查距离、高度差和前方扇形；玩家跑出范围可以躲开。每次挥击最多扣血一次，攻击播完后等待冷却再出手。
- 飞刀命中时扣血并立即进入 Hit，打断移动和未命中的攻击；受击动作播完后重新判断追逐或攻击。连续被不同飞刀命中会重新播放 Hit，每把飞刀对同一个目标只扣血一次。
- 生命归零时立即进入 Death，优先于 Hit。小怪停止移动和碰撞，不再攻击或受伤。死亡动作播完后默认再保留 4 秒，然后移除；也可以选择永久保留尸体。
- 玩家离开追逐范围、被禁用或生命归零后，小怪回到 Idle。警戒范围和放弃范围不同，避免在警戒边缘反复切换。

## 1. 小怪组件

1. 选择代表整只小怪的根物体，添加 **Kaoru Enemy Controller**。Unity 会自动补上 **Rigidbody**、**Capsule Collider** 和 **Kaoru Health**。其他四个状态脚本和状态机脚本是普通 C# 类，不用挂到物体上。
2. 调整 Capsule Collider 的 Center、Height 和 Radius，包住身体。**Is Trigger 关闭**。只使用这一套身体碰撞体即可；模型子物体已有多余的碰撞体或 Rigidbody 时，请检查并整理，避免叠加多套物理驱动。
3. Rigidbody 的 **Use Gravity 开启，Is Kinematic 关闭**。推荐 **Interpolate = Interpolate**。脚本会在运行时冻结物理旋转，通过代码转向，并保留重力方向的速度。模型脚底应与根物体原点对齐；模型正面应朝根物体的本地 +Z，可旋转模型子物体校正。
4. 将玩家根物体拖到 Enemy Controller 的 **Target**。不指定时，**Auto Find Player** 会自动寻找现有的 KaoruTopDownController；后续目标丢失时最多每秒查找一次。
5. 将小怪的 Animator 拖到 **Character Animator**，Animator 在模型子物体上也可以。留空会自动查找。确保 Animator 已启用、已指定 Controller，Avatar 与模型匹配。
6. 在小怪 **Kaoru Health → Max Health** 填写可承受的伤害，默认 **3**。飞刀默认每次扣 **1** 点，即第三次有效命中死亡。禁用再启用不会恢复生命。

## 2. Animator 配置

在小怪的 Animator Controller 的 **Base Layer** 内放入下面五个状态，并分别指定相应动画。状态名称大小写需一致；动画文件本身不用重命名。

| Animator 状态名 | 指定的动画 | Loop Time |
| --- | --- | --- |
| Idle | 待机，例如小怪idle | 开启 |
| Run | 奔跑，例如小怪奔跑 | 开启 |
| Attack | 攻击，例如小怪平A | 关闭 |
| Hit | 受击，例如小怪受击 | 关闭 |
| Death | 死亡，例如小怪死亡 | 关闭 |

将 **Idle 设为默认状态**。五个状态的 **Speed 设为正数**，通常为 1；不绑定未配置的速度参数。

这套脚本直接选择 Animator 状态并平滑混合，**无需增加 Parameters、Animation Events 或过渡连线**。这五个状态之间不要保留自动 Transition，也不要添加会切走它们的 Any State Transition，以免与脚本争抢播放权。运行时脚本会关闭 Apply Root Motion，位移由 Rigidbody 负责。

如果你已将状态命名为“奔跑、攻击、受击、死亡”，可以保留，在 Enemy Controller 的 **Animator State Names** 中填写实际名称。也支持完整路径，例如 Base Layer.攻击，或子状态机路径 Combat.Attack。这里填的是 Animator 图中方框的状态名，不是 FBX 文件名或动画片段名。

Loop Time 在动画资源的导入设置中调整。这里仅检查代码，没有替你修改动画资源。若当前 Animator 编辑尚未保存，请先保存。

## 3. 玩家与飞刀

- 要让小怪攻击实际扣玩家生命，在玩家根物体上添加 **Kaoru Health**，例如设置 **Max Health = 10**。未添加时仍会播放攻击，首次可命中时 Console 会提示缺少生命组件。
- 现有飞刀上的 **Kaoru Throwing Knife** 已加入 **Damage**，默认 1。可以在飞刀 Prefab Inspector，或玩家 Knife Thrower 的飞刀参数折叠栏中修改。飞刀仍使用原来的反弹、插入目标和消失逻辑。
- 飞刀使用 **3D Rigidbody + 非 Trigger Collider**，小怪身体也使用非 Trigger Collider。检查 Physics 的 Layer Collision Matrix，确保飞刀和小怪所在层允许碰撞。
- 小怪的 Collider 要覆盖飞刀的飞行高度。若刀从身体上方飞过，调整小怪碰撞体，或现有 Knife Thrower 的 Override Launch Height / Launch Height。
- 生命组件的 **On Damaged / On Died** 可在 Inspector 中连接音效、特效或 UI。玩家死亡动画、玩家停止操作和重生不属于这套小怪逻辑，可通过玩家 On Died 另行接入；小怪发现玩家生命归零后会停止追逐。

## 4. 常用参数

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| Detection Radius | 8 | 从 Idle 发现玩家的距离 |
| Lose Target Radius | 12 | 已追逐后放弃目标的距离 |
| Max Height Difference | 2 | 双方根物体允许的高度差 |
| Run Speed | 3 | 每秒追逐距离 |
| Turn Speed | 540 | 每秒转向角度 |
| Attack Range | 1.5 | 首次开始攻击的距离 |
| Attack Exit Range | 1.8 | 已近身后，重新追逐的边界；边界内可继续攻击 |
| Attack Hit Range | 1.8 | 命中帧的最大有效距离 |
| Attack Arc | 120 | 正前方有效命中扇形的总角度 |
| Attack Hit Time | 0.4 | 动画播放到 40% 时检查命中 |
| Attack Cooldown | 0.8 | 每次攻击结束或被打断后的等待秒数 |
| Attack Damage | 1 | 每次有效挥击伤害 |
| Animation Blend Time | 0.08 | 动画切换的混合秒数 |
| Despawn After Death | 开启 | 是否自动移除尸体 |
| Corpse Lifetime | 4 | 死亡动画结束后额外保留的秒数 |

距离按双方根物体在 **XZ 平面**上的间距计算。攻击距离应略大于双方身体碰撞体的半径之和，否则身体已经互相挡住，小怪却仍未到达攻击距离。建议 Attack Hit Range 不小于 Attack Exit Range。

Attack Hit Time 应调到攻击动作真正挥到玩家的那一帧。攻击、受击和死亡的结束均按 Animator 的实际播放进度判断，修改动画长度或状态速度后不需要另填持续时间。攻击前摇会朝向玩家，命中判定后锁定朝向，直到本次动作结束。

选中小怪时，黄色线表示警戒范围，红色线表示首次攻击范围，灰色线表示放弃追逐范围。

## 移动范围

当前采用 Rigidbody 沿 XZ 平面直接接近玩家，保留与地形、墙体的物理碰撞；**没有寻路和视线遮挡判断**。墙体会挡住小怪的移动，但它不会绕墙，也可能对攻击距离内、墙另一侧的玩家造成伤害。先用于空旷战斗区域；复杂关卡可在此状态机上替换追逐移动，并添加视线检测。

## 文件职责

- **KaoruEnemyController**：组件引用、移动、目标检测、攻击判定和 Animator 播放。
- **KaoruEnemyStateMachine**：进入、更新、退出当前状态。
- **KaoruEnemyIdleState / ChaseState / AttackState / HitState / DeathState**：五种行为。
- **KaoruHealth**：玩家和小怪可共用的生命与受伤、死亡事件。
- **KaoruThrowingKnife**：在现有物理碰撞中向被命中对象或其父物体上的 KaoruHealth 扣血，并排除投掷者自身。
