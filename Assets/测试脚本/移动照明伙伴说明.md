# 移动照明伙伴

脚本为同目录的 **KaoruLightCompanion.cs**。只新增代码和说明，不修改场景、角色控制器、灯光资源或渲染设置。参考视频中的悬浮照明伙伴，实现斜上方光源、地面前方照明、平滑跟随与转向、上下悬浮；具体画面仍需在你的场景中调节并测试。

## 在场景中布置

1. 新建一个空物体，命名为 **LightCompanion**，放在场景根目录，Scale 保持 **1, 1, 1**。给它添加 **Kaoru Light Companion** 组件。
2. 把你已有的 **Spot Light + Volumetric Light Beam HD** 灯光对象拖到 LightCompanion 下面，作为子物体；子物体 Local Position 设为 **0, 0, 0**，Local Scale 设为 **1, 1, 1**。灯光和 VLB HD 必须在同一个对象上。脚本会控制它的旋转，不需要手动设置照射角度。
3. 将 **Kaoru 角色根节点**拖入脚本的 **Target**。应当是挂有 KaoruTopDownController 和 Rigidbody 的节点，不要拖动画骨骼。
4. 将灯光上的 **VolumetricLightBeamHD** 组件拖入 **Beam**，也可以留空让脚本在自己及子物体中查找。
5. 先保留脚本默认参数，进入 Play 模式，用 WASD 行走、转身、停止和攻击来检查效果。脚本进入运行状态后才会摆放灯光；编辑时选中 LightCompanion，可以用浅蓝色 Gizmos 预览光源位置和瞄准点。

只有一个灯光对象时，也可以直接把脚本挂到现有 Spot Light 上，再设置 Target 和 Beam。未来加入伙伴模型时，建议使用上面的空父物体结构：模型与 Spot Light 并列作为子物体，模型会随父物体保持直立，只有灯光向下倾斜。不要把脚本挂到 Kaoru 本体或 Kaoru 的父节点上。

## 运行行为

- 读取角色经过 Rigidbody 插值后的 Transform，在 LateUpdate 跟随，不创建输入设备，不修改移动或 Animator。
- 默认根据 KaoruTopDownController 的移动方向缓慢转向，位置在角色斜后上方，光束瞄准前方地面。移动停止后保留最后的方向，尚未完成的缓动会继续收敛。
- Kaoru 攻击时跟随角色攻击朝向，避免仍按着移动键导致灯光照向另一个方向。
- 没有 KaoruTopDownController 时，自动改用目标的实际水平位移判断方向；静止微小抖动不会改变朝向。
- 跟随地形高度，上下漂浮只作用于光源，瞄准点不跟随漂浮。暂停时停止运动。
- 初次启用、重新启用、更换 Target 或角色传送时立即摆到附近。位置平滑使用独立世界坐标，即使作为角色子物体，也能保留跟随延迟；推荐放在场景根目录以避免继承角色缩放。
- 不自动启用或禁用 Spot Light / Beam，不改颜色、强度、范围、锥角、噪声或质量。只按 VLB 现有的灯泡开关及倍率同步 Spot Light 的属性，不需要额外添加 Track Realtime Changes On Light HD，也不会每帧重新生成光束网格。

## 参数起点

| 参数 | 默认值 | 调节效果 |
| --- | --- | --- |
| Follow Offset | X 0.85 / Y 2.4 / Z -1.1 | X 是照明方向右侧，Y 是高度，Z 是前后。X 设为负数可换到左侧。 |
| Follow Smooth Time | 0.22 秒 | 越大越有追随拖尾；0 表示立即跟随。 |
| Turn Speed | 180 度/秒 | 越小，转向时绕到新位置越慢。 |
| Follow Movement Direction | 开启 | 关闭后始终照向角色正面，适合其他移动控制器或原地转身。 |
| Movement Threshold | 0.1 米/秒 | 仅在没有可用 Kaoru 控制器时，用于过滤位移抖动。 |
| Teleport Distance | 8 米 | 角色单帧移动超过此距离时立即跟上；0 关闭传送检测。 |
| Look Ahead Distance | 2.5 米 | 照向角色前方的距离；0 则照向脚下。 |
| Aim Height | 0.1 米 | 相对于角色根节点的瞄准点高度。若根节点在腰部，需要相应减小。 |
| Aim Smooth Time | 0.08 秒 | 光束方向的额外缓动；0 表示立即瞄准。 |
| Hover Amplitude | 0.06 米 | 悬浮幅度；0 关闭。 |
| Hover Frequency | 0.7 次/秒 | 悬浮频率；0 关闭。 |

## 现有 VLB 和 Unity Light 设置

可以先保留截图中的 **Intensity 0.35、Range 约 10.3、Spot Angle 约 82°、Source Radius 0.1、Jittering 0、Noise Disabled**。它们是你当前效果的起点，脚本不会替你改写。

截图中带黄色灯泡图标的强度、距离和锥角，当前由同对象的 **Unity Spot Light** 驱动。优先在 Light 上调节相应数值，VLB 会按已有倍率同步。需要单独降低光束而保留地面亮度时，可以调节 VLB 的强度倍率。

VLB 负责看得见的体积光束，真正照亮地面、角色和草地的是 **Unity Spot Light**。如果只有光束没有地面亮斑，检查 Light 是否启用、Mode 是否为 **Realtime**、Culling Mask 是否包含场景层，以及地面和草地材质是否接受附加灯光。

需要墙壁或树干遮挡体积光时，可自行给灯光增加 **VolumetricShadowHD**，并让 Update Rate 包含 **On Beam Move**。地面和模型的普通阴影由 Spot Light 的 Shadows 控制。脚本不做伙伴寻路、避障或自动改写阴影设置。前方瞄准点以角色根节点高度为基准，没有额外向地形射线贴地；陡坡处可调整 Aim Height 和 Look Ahead Distance。

## 建议测试

检查直跑、斜跑、连续转向、180° 掉头、松键停止、攻击转身、上下坡、暂停恢复，以及重新启用组件。先确认角色和脚边能被照亮，再调照射距离、偏移和缓动，让画面接近参考视频。
