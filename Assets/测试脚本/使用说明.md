# Kaoru 俯视角控制

当前“场景”里的 Kaoru 已经配置并保存，直接进入 Play 模式即可操作。运行验证已通过四向奔跑、斜向等速、松键待机、左右转向混合、转向及掉头后恢复 RunA、奔跑动画进度连续、AttackA1 攻击停步、攻击结束恢复移动，以及再次攻击。

如果需要重新配置或给另一个 Kaoru 实例使用，在 Unity 中选择 **Kaoru 根对象**，执行菜单 **Tools > Kaoru > Configure Selected Character**，保存场景后进入 Play 模式。

配置工具会挂载 KaoruTopDownController，使用本文件夹内独立的 KaoruGameplay 动画控制器。待机使用 Idle_A；攻击使用展示场景的 **AttackA1**（素材片段 Atk_A1_wing），复制到 KaoruAttack 并关闭循环。原素材资源不需要修改。

奔跑状态使用一维 Blend Tree，Turn 参数为负时混合 **RunA_L**，为零时播放 **RunA**，为正时混合 **RunA_R**。Turn 根据角色当前朝向与移动方向的夹角平滑变化，转向越大，转向片段权重越高；方向对齐后平滑回到 RunA。三个奔跑片段共享同一状态的播放进度，避免每次转向都从第一帧重新起跑。这里的左右是角色实际转向，与是否按 A/D 没有固定对应关系。

Animator 窗口中的 Idle、Run、Attack 三个状态由脚本直接切换，不需要手动连线。重复执行配置菜单会更新已有动画资源，保留场景引用。

- **W / A / S / D**：按游戏相机的方向奔跑，松开后待机，斜向速度与直线相同。
- **鼠标左键**：朝鼠标所在的地面方向攻击一次。攻击期间停步，再次点击不会中断当前攻击；结束后根据按键恢复奔跑或待机。
- **点击界面**：鼠标位于 EventSystem 识别的 UI 上时，不触发攻击。

在 Kaoru 的控制器组件上可以调整 Run Speed（奔跑速度）、Turn Speed（转向速度）、Full Turn Animation Angle（转向动画达到完整权重的夹角）、Turn Animation Damping（转向动画平滑时间）、Blend Duration（动画切换时间）、Attack Speed（攻击播放速度）和 Face Mouse When Attacking（攻击朝向鼠标）。

Gameplay Camera 应引用渲染场景的相机。本项目的一键配置优先选取带 PixelCameraManager 的 PixelCamera；不要改为只负责最终画面显示的相机。

角色依靠 Rigidbody 和 CapsuleCollider 与地形碰撞。配置工具会解除素材刚体对水平移动的锁定，保留重力并固定身体旋转，角色转向由脚本控制。场景中的地面和障碍物需要具有 3D Collider。

目前“攻击”实现动作播放及朝向控制，尚未添加敌人命中检测、伤害或连击系统。
