# Kaoru 俯视角控制与 Animator

已通过 Unity 官方 CLI 将控制器部署并保存到 **Assets/Scenes/Demo.unity** 的 **Kaoru**。直接进入 Play 模式即可使用，Gameplay Camera 已绑定到渲染世界的 PixelCamera。

## 操作

- **W / A / S / D**：相对于游戏相机奔跑，支持斜向等速、加速和减速。
- **鼠标左键单击**：上半身连续播放一次 AttackA1 → AttackA2。点击 UI 不攻击。
- **按住鼠标左键**：AttackA2 播完后直接接回 AttackA1，一直循环到松开；松开后播完当前这一套再收手。
- 攻击期间角色不会停下：上半身播放攻击，下半身播放 Walk，以 Attack Move Speed 移动；如果移动方向背离鼠标方向（边攻击边后退），下半身改为 Walk_back。
- 攻击全程身体持续转向鼠标在地面上对应的点（俯视角双摇杆式瞄准）。攻击中重复点击不会重启动作；整套结束后按当前按键恢复奔跑或待机。

攻击动作对应展示面板的 **AttackA1 / AttackA2**，素材为 **Atk_A1_wing / Atk_A2_wing**。AttackA1 和 AttackA2 各从右手投出一把飞刀（见下文“飞刀”），未实现伤害判定。

## Animator 中的配置

打开本文件夹的 **KaoruGameplay.controller**。它有两层：

**Base Layer**（全身移动，下半身在攻击时仍由它驱动）包含 Idle、RunA、AttackWalk 三个状态，Idle 为默认状态：

| 连线 | 条件 | Has Exit Time | 过渡时间 |
| --- | --- | --- | --- |
| Idle → AttackWalk | IsMoving = true 且 Aiming = true | 关闭 | 0.12 秒 |
| Idle → RunA | IsMoving = true 且 Aiming = false | 关闭 | 0.12 秒 |
| RunA → AttackWalk | Aiming = true | 关闭 | 0.12 秒 |
| RunA → Idle | IsMoving = false | 关闭 | 0.12 秒 |
| AttackWalk → Idle | IsMoving = false | 关闭 | 0.12 秒 |
| AttackWalk → RunA | IsMoving = true 且 Aiming = false | 关闭 | 0.15 秒 |

AttackWalk 是一维 Blend Tree：WalkBack = 0 为 Walk_wing，WalkBack = 1 为 Walk_back_wing。脚本按移动方向与瞄准方向的点积选择前进或后退，带 ±0.2 的滞回，横向平移时不会在两者之间抖动。

**Upper Body** 层为 Override 模式，使用本文件夹的 **KaoruUpperBody.mask**（只开启躯干、头、双臂、手指和手部 IK），包含 Empty、AttackA1、AttackA2：

| 连线 | 条件 | Has Exit Time | 过渡时间 |
| --- | --- | --- | --- |
| Empty → AttackA1 | Attack Trigger | 关闭 | 0.06 秒 |
| AttackA1 → AttackA2 | 无 | 开启，Exit Time = 1 | 0.08 秒 |
| AttackA2 → AttackA1 | AttackHeld = true | 开启，Exit Time = 1 | 0.08 秒 |
| AttackA2 → Empty | AttackHeld = false | 开启，Exit Time = 1 | 0.15 秒 |

Empty 没有动作，不覆盖下层姿势。AttackA1 / AttackA2 带 Attack Tag，攻击过程不可中断。

Animator 参数为 **IsMoving（Bool）**、**Turn（Float）**、**Attack（Trigger）**、**AttackHeld（Bool）**、**AttackSpeed（Float，默认 1）**、**Aiming（Bool）**、**WalkBack（Float）**。脚本只写参数；是否处于攻击由 Upper Body 层当前及下一个状态的 Attack Tag 判断，不调用 Play/CrossFade 强制切换状态。

双击 **RunA** 状态可打开一维 Blend Tree：

| Turn 阈值 | 动画 |
| --- | --- |
| -1 | RunA_L_wing |
| 0 | RunA_wing |
| +1 | RunA_R_wing |

左右根据角色的物理朝向与目标移动方向之间的有符号夹角判断。左转使用 RunA_L，右转使用 RunA_R，对齐后回到 RunA；180° 掉头延续上一转向侧，避免左右抖动。三个片段共享播放进度，转向时不重新起跑。转向速度从旧配置的 1080°/秒调整为 540°/秒，让转向动作有可见的播放时间。

AttackA1 / AttackA2 的状态 Speed 均为 1，只由 AttackSpeed 参数控制攻击倍率。KaoruAttack.anim 与 KaoruAttackA2.anim 是独立的非循环片段，退出时间等于完整动作的归一化时长 1。原始 FBX 保持不变。

## 组件调节

在 KaoruTopDownController 上可调整：

- Run Speed：目标奔跑速度，默认 4。
- Turn Speed：物理转身速度，当前 540°/秒。
- Acceleration / Deceleration：水平加速和停止速率，默认 28 / 40。
- Full Turn Animation Angle：转向片段达到完整目标权重的夹角，默认 45°。
- Turn Animation Damping：转向动画混合的平滑时间。
- Attack Speed：AttackA1 / AttackA2 的播放倍率，范围 0.1–3。
- Face Mouse When Attacking：攻击期间是否持续朝向鼠标。
- Attack Move Speed：攻击时（Walk / Walk_back）的移动速度，默认 2。
- Aim Turn Speed：攻击时转向鼠标的速度，默认 1440°/秒。
- Walk Back Damping：Walk 与 Walk_back 之间切换的平滑时间。

角色使用 Rigidbody 和 CapsuleCollider 与 3D 地形碰撞，保留重力、冻结刚体旋转，Root Motion 关闭。Gameplay Camera 应为渲染世界的 **PixelCamera**，不要选择最终输出画面的 ViewCamera。

## 飞刀

角色上的 **KaoruKnifeThrower** 负责“何时、从哪里、朝哪里”投出；飞刀 Prefab（**Assets/道具/飞刀.prefab**）上的 **KaoruThrowingKnife** 负责“怎么飞、命中后怎样”。

两组参数都可以在角色的 Knife Thrower Inspector 里调整：下方的“飞刀物理参数”折叠栏直接编辑所指定飞刀 Prefab 上的 KaoruThrowingKnife。这里修改的是 Prefab 本身，所有使用它的角色共享；Play 模式中的修改也会保留，并对之后投出的飞刀生效。

**KaoruKnifeThrower（角色上）**

- Knife Prefab：要投出的飞刀。每次出手都会新生成一把。
- Held Knife：手上拿着的飞刀模型（当前为 Wrist_R 下的 Kunai）。游戏开始时会移除它身上的 Rigidbody、Collider、Joint 和 KaoruThrowingKnife，只作为跟随手部的模型，不参与物理，也不会被投出。
- Throws：每次出手一项，默认两项：
  - State Name：Upper Body 层的状态名（AttackA1 / AttackA2）。
  - Release Time：出手时刻，按状态归一化时间计。默认 A1 = 0.15、A2 = 0.17，取自动画中手部前挥最快的帧。
  - Hand：出手的骨骼。默认两下都是右手，A2 沿用 A1 的出手位置。
  - Spawn Override：可选，拖入任意 Transform 代替手部骨骼。
  - Spawn Offset：在手部位置上叠加的偏移，角色空间（x 右、y 上、z 前）。
  - Yaw Offset：这一把的额外水平角度，可做扇形。
- Aim At Cursor Point：两把刀都飞向鼠标在地面上的点，而不是从左右手平行飞出。离鼠标太近（Min Cursor Distance）时改用身体朝向。
- Launch Pitch：上下仰角，0 为水平飞行。
- Override Launch Height / Launch Height：所有飞刀统一从脚底以上固定高度出手，不用手的高度。
- Inherit Character Velocity：飞刀叠加角色当前的水平速度。

选中角色时，Scene 视图会用橙色小球和短线标出当前姿势下的出手点。

**KaoruThrowingKnife（飞刀 Prefab 上）**

飞行完全由 Rigidbody 物理模拟：重力、空气阻力、旋转和稳定都是力或力矩，命中时是插住还是弹开，取决于实际撞击的速度和角度。下列数值在出手时写入 Rigidbody，会覆盖 Rigidbody 组件上的同名设置。

- Rigidbody
  - Mass：质量，默认 0.15 kg。越重，撞到带 Rigidbody 的物体时推得越狠；用 Impulse 出手时也飞得越慢。
  - Linear Damping / Angular Damping：线性阻尼（随速度衰减）与旋转阻尼。
  - Gravity Scale：重力倍率，0 为笔直飞行，1 为真实重力，默认 0.3。
  - Override Center Of Mass / Center Of Mass：重心（飞刀本地坐标）。默认偏向刀尖（Z = 0.15），飞刀会自然刀尖朝前。选中飞刀时显示为青色小球。
  - Max Angular Velocity：最大角速度（rad/s）。Unity 默认 7 对飞刀来说太低。
  - Collision Detection / Interpolation：碰撞检测与插值。默认的连续检测可以避免高速穿透。
- Launch
  - Launch Force / Launch Force Mode：VelocityChange 时 Launch Force 就是出手速度（m/s，默认 18），与质量无关；Impulse 时为冲量（N·s），速度 = 冲量 ÷ 质量。
  - Launch Spin：出手角速度（°/s，飞刀本地坐标）。X 为前后翻滚，Z 为沿刀尖自转。
  - Blade Roll：刀身绕刀尖轴的初始转角。刀尖是模型的 +Z；默认 90 让刀面朝上。
- Aerodynamics
  - Stabilization：把刀尖转向气流方向的力矩，相当于箭羽，随速度增大。0 为不稳定。翻滚飞刀可以调低这一项、调高 Launch Spin X。
  - Quadratic Drag：额外的平方空气阻力（力 = k × v²）。
- Surface：Apply Physics Material 开启时，用 Bounciness / Dynamic Friction / Static Friction 为飞刀的碰撞体生成物理材质。
- Hit
  - Hit Behaviour：StickWhenTipHits 为刀尖够快、够正时插住，否则物理弹开；Destroy 为碰到就消失；PhysicsOnly 为从不插住，完全交给物理。
  - Min Stick Speed：插住所需的最小撞击速度，默认 6 m/s。
  - Max Stick Angle：刀尖与表面法线的最大夹角，默认 60°。
  - Stick Depth：插入深度。
  - Stick To Moving Targets：命中带 Rigidbody 的物体时是否跟随。
- Lifetime：没插住的飞刀（飞行中、弹开或掉在地上）在出手后多少秒消失；Stuck Lifetime 为插住后多少秒消失。

飞刀会自动忽略与投掷者自身碰撞体的碰撞。伤害可订阅飞刀的 **Hit** 事件实现（每次插住前的碰撞都会触发，参数为飞刀和 Collision）。

## 相机跟随

Demo 场景的 **PixelCameraSystem** 已挂载 **KaoruPixelCameraFollow**，Target 为 Kaoru。跟随只移动这个父级，保持场景里原有的镜头偏移和旋转角度。PixelCameraManager 继续使用同级的 **PixelCameraTransform** 作为内部锚点，并负责 PixelCamera 的网格对齐及亚像素校正。

跟随在 LateUpdate 中读取角色经过刚体插值的位置，执行顺序为 -100，先移动父级，再由 PixelCameraManager 完成像素校正。Smooth Time 默认 0.12 秒，设为 0 可立即跟随；Follow Height 决定是否跟随地形高度。角色转身不会旋转镜头。

在其他场景手动布置时，将 KaoruPixelCameraFollow 挂到 **PixelCameraSystem**，将角色拖到 Target，并在进入 Play 前摆好镜头位置。也可选中角色，执行 **Tools > Kaoru > Configure Camera Follow**，再保存场景。完整的 Configure Selected Character 菜单也会配置这项绑定。

## 重新部署或给其他角色配置

1. 在场景选中 Kaoru 根对象，或选中其模型子对象。
2. 执行 **Tools > Kaoru > Configure Selected Character**。
3. 保存场景。

工具会更新本文件夹专用 Animator 的状态、连线、参数和 Blend Tree，添加 Knife Thrower 并指定飞刀 Prefab（Prefab 缺少 KaoruThrowingKnife 时会自动补上），保留控制器 GUID、根状态机、已有状态节点和 Blend Tree 的引用，重新绑定相机和角色组件。这样在 Animator 窗口打开时重复部署，也不会因面包屑引用失效而显示空白。已存在的独立攻击片段会保留；重复部署不会增加重复状态或连线。
