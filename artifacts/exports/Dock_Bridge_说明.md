# Dock 桥资源包

源资源：Assets/逆向出来的物体/Dock.prefab

导入方法：在 Unity 中选择 Assets > Import Package > Custom Package，打开 Dock_Bridge.unitypackage，导入后将 Dock.prefab 拖入场景。

包含桥网格、预制体、材质、贴图，以及自定义 Shader Graph、子图和 HLSL 依赖。包内保留原资源路径和 GUID。

原项目版本：Unity 6000.3.7f1，URP / Shader Graph 17.3.0。目标项目需要启用兼容版本的 Universal Render Pipeline 和 Shader Graph；Unity 标准包由目标项目的 Package Manager 管理。

资源保留原预制体的位置、层级与碰撞体。导入后可按需调整位置。
