# 大树与小树的叶片恢复、手动调试

修复日期：2026-10-28。场景：`Assets/场景/ZQY.unity`。

## 为什么球形树冠不长叶子

1. 小树 `Tree (10)` 被填入了适用于巨大缩放模型的参数：Density 为 `0.000004`、Scale 为 `0.008`。这棵小树实际缩放为 1，原脚本会尝试生成约 49,564,847 片叶子，Console 已出现 `OutOfMemoryException`。它由父对象 `Trees` 合并生成，一棵树的异常会使整组生成中断。Scale 为 0.008 还会让单片叶子缩得很小。
2. 大树模型有 147,607 个顶点，采用 UInt32 索引。旧脚本提取树冠时创建了默认 UInt16 网格，树冠的 84,960 个索引全部发生了错误转换，叶子因此出现在树干附近。
3. 当前改良版模型已变为两个子网格：`0` 是树干，`1` 是球形树冠。之前三个子网格版本的树冠编号 `2` 不再适用。
4. 当前大树缺少生成组件，模型 Read/Write 也被关闭，已一并恢复。
5. 这套动态叶片组件只在 Play 模式运行。停止 Play 后只看到球形树冠是正常现象，进入 Play 才会生成叶片。

## 已完成的修复

- 保留源模型 UInt32 索引格式，准确提取树冠；读取 sharedMesh，避免复制并替换源网格。
- 释放临时采样网格，跳过无效子网格，不再回退到整棵树生成。
- 新增 Max Instances 数量上限；极小 Density 会受到限制并提示警告，避免再次申请数千万片叶子的内存。
- 父级合并器跳过无效来源，使其他正常树木仍可生成。
- 优化三角形抽样搜索，并修复小尺寸三角形的法线归一化。
- 保存了场景及 `Assets/场景/qy模型/巨大的树改良版.prefab`，场景大树只有一个生成组件。

## 手动让大树长满叶子

1. 停止 Play。选中 Project 中的 `Assets/场景/qy模型/巨大的树改良版.fbx`，在 Inspector 的 **Model → Read/Write** 勾选，再点 **Apply**。生成脚本需要读取顶点和三角形数据；此设置的含义见 [Unity 模型导入设置](https://docs.unity.com/en-us/engine/6000.3/manual/assets-and-media/asset-types/models/importing/fbximporter-model)。
2. 在 Hierarchy 选中“巨大的树改良版”。确认 **Mesh Instances Behaviour** 组件存在且启用；缺少时通过 Add Component 搜索 `MeshInstancesBehaviour`。只保留一个生成组件。
3. 按上表填写大树参数，展开 **Instancing Settings → Element 0**，指定 Tree_Leaf 与 Instanced_Leaves。当前模型树冠编号为 **1**。
4. 保存场景，再进入 Play 查看。若在 Play 中调参数，生成数据不会立即自动重建，而且退出 Play 会丢失这些参数修改。最稳妥的流程是：**停止 Play → 调参数 → 保存 → 进入 Play**。
5. 小树同样按上表的小树列填写。小树在 Play 中由父对象 Trees 合并绘制，其自身组件变为禁用是正常现象，不要再手动启用一份而造成重复绘制。

## 怎么继续调

- **更密**：降低 Density；**更疏**：提高 Density。这个脚本中的数量约等于“模型局部表面积 ÷ Density”。数值含义与名称的直觉相反。
- **叶片更大**：提高 Scale；更小则降低。小树可从 0.8–1.2 试，大树可从 0.012–0.02 试。
- **叶片离球面更远**：提高 Normal Offset。当前大树建议从 0.0005–0.001 试；不要填 1，因为偏移还会乘以模型缩放。
- **控制数量**：保留 Max Instances。看到 capped 警告时，先提高 Density，避免直接把数量上限调得很大。
- **只改这棵大树的叶色**：先复制 Instanced_Leaves 材质，再把副本拖到大树的 Material 槽，避免连带更改其他树的颜色。
- **换模型或重新导出 FBX 后**：重新确认树冠子网格编号、Read/Write 和缩放，不能沿用旧模型编号。

如果大树保持均匀缩放 S，要获得与缩放为 1 的小树相近的世界尺寸和密度，可以用：

```text
大树 Density       = 0.2 / (S × S)
大树 Scale         = 1 / S
大树 Normal Offset = 0.05 / S
```

以上换算假定树冠网格采样使用局部坐标，且三个方向缩放相同；非均匀缩放需另行调整。
